## Why

当前控制器空间圆盘使用整个文件系统的 `used/total`，会把项目外的系统和用户文件混入展示；同时系统设置已有的本地运行路径没有完整映射到看板，运维人员无法直观看到 HPCDeploy 各模块真正占用了多少空间。

## What Changes

- 将圆盘统计口径改为仅覆盖 HPCDeploy 项目内部的本地模块，不再显示或计算“分区其他占用”。
- 复用系统设置中的本地运行路径，展示 SQLite、备份、任务产物、SSH keys、MPI/压测脚本、GPU 驱动库、临时驱动、Apptainer 和其他项目运行文件。
- 圆盘中心显示项目总占用，各颜色分段显示模块占用比例；明细展示大小、文件数、路径和状态。
- 保留 `/dev/sdd` 和挂载点作为辅助定位信息，但不参与项目圆盘百分比计算。
- 移除独立的“服务器”和“任务运行”大卡片，将在线/离线、运行中/等待中等数字合并到运行状态或运行中任务区块标题，避免与任务表重复。
- 保留近期已完成任务及任务结果信息，但降低其首屏优先级。

## Capabilities

### New Capabilities

无。本次属于现有 Dashboard 与运行数据生命周期能力的修正和扩展。

### Modified Capabilities

- `runtime-data-lifecycle`: 修改控制器空间统计口径，要求只统计项目本地模块并提供模块化占用明细。

## Impact

- 后端 Dashboard storage schema 和 summary API：从文件系统容量统计改为项目路径分类统计，并返回文件数、项目总占用和模块状态。
- 前端 Dashboard 类型、圆盘图、模块明细、路径展示和运行状态布局。
- 复用系统设置已有运行路径定义，保持远端任务目录不计入本机项目空间。
- 更新后端/前端测试及 `docs/architecture.md`、`docs/progress.md`；不改变清理、任务执行或容量阻断策略。
