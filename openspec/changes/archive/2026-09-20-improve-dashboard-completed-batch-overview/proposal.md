## Why

Dashboard 的“近期已完成任务”目前按子任务逐条展示，批次任务会被拆成多行，操作员无法在首页快速判断一个批次的整体结果、失败规模和完成范围。历史页已有批次聚合和详情能力，应将这套语义延伸到 Dashboard，保持首页轻量但提供完整批次入口。

## What Changes

- Dashboard 近期已完成任务按展示条目聚合：一个批次一行，单次任务保持一行。
- 批次行展示批次 ID、任务类型、服务器数、子任务数、整体状态、成功/失败摘要和完成时间。
- 批次整体状态复用历史页的状态与最终结果判定，支持全部成功、部分失败、失败和取消等结果。
- 批次行提供现有批次详情入口，进入后查看完整子任务、证据和结果文件。
- “最近 10/20/50 条”按聚合后的展示条目计算，不再按子任务行数截断批次。
- 运行中任务保持现有逐子任务展示、刷新和跳转行为不变。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `task-results-observability`: Dashboard 近期完成任务需要同时支持单次任务和批次整体摘要，并保持批次详情与最终结果语义一致。

## Impact

- 后端 `/api/dashboard/summary` 响应新增近期完成批次摘要，可能需要复用现有批次汇总服务或查询逻辑。
- 前端 `Dashboard.vue`、Dashboard API 类型和源码测试需要支持单次/批次混合展示。
- 现有任务历史批次页、运行中任务列表和任务详情接口保持兼容，不改变任务数据和远端执行行为。
- 需要补充批次完整性、部分失败、报告级失败、空列表和分页/显示数量边界测试。
