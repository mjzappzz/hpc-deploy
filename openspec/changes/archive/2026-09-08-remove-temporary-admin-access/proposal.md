## Why

管理员临时授权功能允许在启用开关时绕过管理员密码取得高风险操作权限，即使令牌短时且绑定标签页，仍扩大了生产控制台的权限提升攻击面。管理员授权应始终以服务端验证管理员密码为前提。

## What Changes

- 移除前端管理员解锁弹窗中通过吉祥物连击请求无密码授权的交互。
- **BREAKING** 移除后端临时管理员授权 API、可用性 API、环境开关与一次性无密码令牌签发逻辑。
- 保留管理员密码验证、时限/标签页会话、HttpOnly Cookie、受保护端点校验及登出行为。
- 添加回归测试，确保任何环境均无法通过无密码路径获得管理员会话。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `admin-governance`: 管理员权限只能在服务端成功验证管理员密码后签发，不再提供临时无密码授权。

## Impact

- 前端管理员确认流程与认证 API 客户端。
- 后端认证路由、配置和令牌辅助逻辑及其测试。
- 部署环境中 `HPCDEPLOY_TEMPORARY_ADMIN_MODE_ENABLED` 将不再生效；不涉及数据库迁移。
