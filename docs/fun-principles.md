# 趣味性设计原则

适用于修改 `frontend/src/components/AppCritters.vue`、趣味文案或相关交互时。与任务执行、权限和安全无关的视觉调整也必须遵守本文件；通用前端架构请参阅 [architecture.md](architecture.md)。

> 生效日期：2026-07-08

## 原则

HPCDeploy 是一个正经的运维工具，但**正经 ≠ 死板**。在不影响功能使用、不增加资源开销的前提下，适当加入趣味元素，让运维工作不那么枯燥。

## 适用范围

所有用户可见的界面层：按钮文案、加载提示、空状态、小交互反馈。

## 规则

### 1. 搞怪但不碍事

- 趣味元素**不能阻挡或干扰**正常操作路径
- 不能导致操作延迟或卡顿
- 不能遮挡关键信息

### 2. 低资源开销

- 趣味元素优先使用 **CSS 动画 + Unicode 字符**，禁止引入额外图片/库
- 禁止使用大体积资源（gif、视频、第三方动画库）
- 定时器只用于煤球状态与发言；关闭或卸载时必须清理

### 3. 适可而止

- 同一个用户会话中，相同趣味文案不重复出现
- 错误/警告场景不要开玩笑（如 "SSH 连接失败" 时保持严肃）
- 用户连续操作时不刷屏

### 4. 有退路

- `prefers-reduced-motion` 媒体查询降级：检测到用户开启系统减少动效时，所有动画失效
- 所有趣味文案不影响国际化（目前无 i18n，后续如需则统一管理）

## 已实现

| 位置 | 类型 | 实现方式 |
|------|------|----------|
| 全局安全悬浮煤球陪伴 | Vue + CSS 动效 | `AppCritters.vue` 在普通路由右下安全位保留唯一煤球 |
| 检测加载文案 | 随机文案 | `useFunMessages.ts` 吐槽池，SSH 检测时随机抽取 |
| 空状态文案 | 趣味文案 | 各页面 `el-empty` description 替换为搞怪文本 |

## 煤球设计规范（AppCritters.vue）

- **配色**：纯黑色系（`#1a1a1a` ~ `#0d0d0d`），不许五颜六色
- **造型**：固定名称为“煤球”的圆形毛绒黑煤球、白眼黑瞳与少量小脚；不使用手、角、天线、随机编号或其他角色。
- **语言**：全中文、低频、非评判式的值守、收尾与轻幽默文案；不揣测用户情绪，不在故障或告警当下开玩笑。
- **行为**：煤球在应用级安全悬浮位以探头进入、安静值守、上下文回应和路由切换时平稳跟随呈现；不按固定短生命周期随机替换。
- **呈现**：煤球默认持续陪伴，不提供正常、安静或关闭的用户模式选择；系统开启减少动效时不生成煤球。
- **实现**：Vue 受控渲染 + CSS 动效 + MutationObserver，零图片；组件卸载和关闭时必须清理观察器与定时器。

## 煤球交互与可读性

- **投放范围**：全部普通路由均在应用级安全悬浮位保留煤球；弹窗、抽屉、通知、管理员确认、危险操作、错误或告警可见时，煤球本体留在安全位但收起气泡、不可抢焦点且不遮挡控件。
- **数量与生命周期**：全局严格只保留一只煤球；路由切换时保持同一实例，不以定时器维持随机数量。
- **独白与回应**：只在明确任务成功节点低频回应；失败或取消保持静默；悬停或触屏轻触可获得一句回应。气泡无安全空间时不显示。
- **定位与避让**：煤球默认约 26px、固定在内容区右下安全位；造型为蓬松圆脑袋与两只清晰的小短脚，毛边不向下扩散成底泥；使用立体黑灰渐变和轻量呼吸动效，名称仅在悬停或键盘聚焦时显示。
- **动效与无障碍**：煤球本体使用平滑浮动和淡入淡出；可用键盘聚焦和点击回应。系统开启 `prefers-reduced-motion` 时不生成煤球。

## 趣味文案池位置

- 煤球文案池：`frontend/src/components/AppCritters.vue` 中的 `WATCHING_MESSAGES`、`COMPLETE_MESSAGES`、`MANUAL_MESSAGES`
- 运维吐槽（加载文案）：`frontend/src/composables/useFunMessages.ts`
